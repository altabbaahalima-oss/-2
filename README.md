# دوائي | نموذج أولي بدون تسجيل دخول

تطبيق عربي باتجاه RTL وتصميم أخضر ورمادي، يتضمن ثلاث صفحات:
1. صفحة البداية والتعريف بالتطبيق.
2. بيانات التواصل (كل الحقول اختيارية ويمكن تخطيها).
3. جدول الأدوية، إضافة المواعيد، تسجيل الجرعات، تجهيز تقرير البريد، وفتح تطبيق الاتصال.

## الملفات
- `index.html`: بنية الصفحات.
- `style.css`: تصميم متجاوب مع الجوال.
- `script.js`: التنقل، حفظ البيانات محليًا، إدارة الأدوية والتذكيرات.
- `README.md`: هذه التعليمات.

## تشغيل ورفع المشروع
1. افتح `index.html` في المتصفح للاختبار.
2. أنشئ مستودعًا جديدًا في GitHub وارفع الملفات الثلاثة وملف README إلى جذر المستودع.
3. افتح Settings → Pages، واختر `main` ثم `/(root)`، واضغط Save.
4. انتظر رابط GitHub Pages.

## ملاحظات السلامة والحدود
- لا يوجد تسجيل دخول؛ التنقل بين الصفحات متاح مباشرة، ويمكن تخطي صفحة التواصل.
- البيانات تُحفظ في `localStorage` على المتصفح والجهاز نفسه فقط.
- التذكيرات تعمل أثناء بقاء صفحة التطبيق مفتوحة، وبحسب دعم المتصفح وإعداداته.
- زر الاتصال يفتح تطبيق الهاتف ويحتاج المستخدم إلى بدء المكالمة بنفسه. صفحة ويب لا تضمن إجراء مكالمة طوارئ تلقائية.
- زر التقرير يفتح تطبيق البريد برسالة جاهزة، ولا يرسل البريد بنفسه.
- هذه نسخة تعليمية أولية وليست نظامًا طبيًا معتمدًا. لا تعتمد عليها وحدها لتنظيم علاج شخص أو التعامل مع الطوارئ.
